# Modern Business Website Template

A clean, responsive one-page website template designed for small businesses like cafes, gyms, and coaching centers.

## 🔹 Features
- Hero section with call-to-action
- About section
- Services section
- Contact information
- Responsive design

## 🔹 Tech Used

- CSS3
- 
- Google Fonts
- GitHub Pages Deployment
